Shri Hanuman Chalisa - reading page (Hindi / English, audio sync)

Files
  index.html                      - poora page (photo, CSS, JS sab andar hai)
  audio/hanuman-chalisa-audio.mp4 - recording (page isi ko chalata hai)

Kaise chalayein
  1. Poora folder kisi web hosting par upload karein (index.html aur audio/ folder saath rakhein).
  2. Ya computer par test ke liye folder mein ye chalayein:  python3 -m http.server
     phir browser mein http://localhost:8000 kholein.
  index.html ko seedha double-click karke bhi khol sakte hain, par tab "download %" wali ring
  nahi dikhti; audio phir bhi chalta hai.

Dhyan dein
  - Recording ka copyright/license aapki zimmedari hai. Public karne se pehle pakka kar lein.
  - Akshar ka font Google Fonts se aata hai (internet chahiye); na ho to system font chalta hai.
  - Sync ki timing audio.mp4 ke hisaab se hai (index.html mein LT aur LE arrays). Audio badlen
    to ye timing bhi badalni hogi.
